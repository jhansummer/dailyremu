이번 주 서울 정비사업에서는 **시공사 선정 경쟁보다 인허가 속도를 높이려는 서울시의 제도 변화**가 눈에 띈다. 이 글에서는 서울시의 정비사업 속도 평가, 서계통합구역 시공사 구도, 신속통합기획 사례의 조합설립 속도, 내일 마감하는 목동4단지 입찰을 정리한다.

---

## 1. 서울시, 정비사업 '속도 평가' 첫 도입

메트로신문(11월 8일) 보도 기준이다.

| 항목 | 내용 |
|---|---|
| 평가 대상 | 25개 자치구, 9월 기준 집중관리 정비사업 522곳 |
| 배점 | 기본 100점(정량 70점 + 정성 30점), 인허가 처리 속도가 60점 |
| 처리기한 예시 | 조합설립인가 30일, 사업시행계획인가 90일, 관리처분계획인가 180일 |
| 가감점 | 조직 운영·역량 강화 가점 최대 20점, 정비사업 정보몽땅 정보공개 미흡 시 최대 10점 감점 |
| 선정 | 12월 우수 자치구 5곳 |
| 조합 포상 | 「신통 2.0 공정촉진 모범 표창」 10곳(재개발 4·재건축 4·모아주택 2) |
| 추천 마감 | 자치구별 최대 2곳, 11월 20일까지 추천, 12월 초 심사 |
| 인센티브 | 2027년 재개발 보조금 우선 지원, 행정 노하우 공유 |

- 정비구역 지정 구역은 6월까지 약 30만 7,000가구이고, 2026~2028년 착공 목표는 약 8만 5,000가구다.
- 서울시의 목표는 2031년까지 31만 가구 착공이다.
- 처리기한을 넘길수록 점수가 깎이므로 자치구 인허가가 빨라질 수 있다. 다만 실제 사업 기간이 줄어드는지는 평가 이후의 인가 소요 기간으로 확인해야 한다.

## 2. 신속통합기획 사례: 초기 단계는 빨라지는 중

파이낸셜뉴스(10월 1일) 보도 기준이다. 모두 정비구역 지정·조합설립 등 초기 단계이며 전체 사업에서는 시작 단계다.

| 사업지 | 규모 | 진행 상황 |
|---|---|---|
| 광진 자양4동 A구역 | 2,999가구, 지하 3층~지상 49층 | 정비구역 지정 후 약 1년 2개월 만에 조합설립인가, 동의율 80.56%(1,559명 중) |
| 중랑 상봉13구역 | 1,249가구, 최고 37층 | 정비구역 지정 후 약 1년 6개월 만에 조합설립인가 |
| 광진 중곡1동 A구역 | 2,200가구, 최고 35층 | 후보지 선정 후 약 1년 7개월 만에 지정안 수정가결, 용도지역 3종 상향 |
| 노원 상계한신3차 | 464가구, 최고 35층, 용적률 299.93% | 입안 제안 후 11개월 만에 정비구역 지정 요청(지정 전) |

- 노원구에서는 민선9기 출범 후 약 3개월간 상계보람·하계미성·상계주공7단지·중계주공4단지·상계마들대림이 추진위 구성 절차를 밟고 있다. 중계주공4단지 동의율은 71.59%, 상계주공7단지는 66.6%다.

## 3. 서계통합구역: 삼성물산 불참, GS건설·대우건설 2파전

머니투데이방송(11월 11일) 보도 기준이다. 재건축이 아닌 재개발 사업장이다.

| 항목 | 내용 |
|---|---|
| 위치·규모 | 용산구 서계동 33번지 일대 11만 2,953㎡, 지하 3층~지상 최고 39층 20개 동, 2,937가구(오피스텔 246실 포함) |
| 진행 | 지난해 4월 정비구역 지정, 7월 2일 조합설립인가 |
| 시공사 선정 | 내년 초 공고 예정, 건설사들은 연말 내부 보고 후 참여 결정 |
| 삼성물산 | 용산구 내 다른 사업장에 집중하기 위해 불참 방침 |
| GS건설 | 가장 적극적, 미국 설계사 SMDP와 대안설계 협업, 성수1지구 수주전 인력 일부 배치 |
| 대우건설 | 내년 주요 수주 후보지로 선정, 청파1구역 수주 이후 의지 |
| 변수 | 정비계획 변경·용적률 상향·중대형 비중 확대 검토 중이라 규모와 공사비가 달라질 수 있음 |

- 공사비는 기사에 나오지 않았다.
- 2파전이 성립해도 사업 규모가 바뀌면 공고 시점과 입찰 조건이 달라질 수 있다.

## 4. 목동4단지: 11월 16일 오후 2시 입찰 마감

지난주 글에서 다룬 일정이 내일이다. 머니투데이방송(9월 30일) 보도 기준이며, 마감 결과는 아직 나오지 않았다.

| 항목 | 내용 |
|---|---|
| 사업 규모 | 1,382가구 → 최고 49층 2,436가구 |
| 예정 공사비 | 1조 6,389억원(3.3㎡당 1,010만원) |
| 입찰보증금 | 600억원, 컨소시엄 불허 |
| 전망 | 제안서 작업에 착수한 곳은 현대건설뿐, 단독 응찰 가능성이 큼 |

## 5. 잠실장미: 11월 중순 공고 목표, 확인 안 됨

머니투데이방송(10월 8일) 보도 기준이다.

- 9월 30일 제5차 이사회에서 시공자 입찰방법·선정계획서가 찬성 5, 반대 6, 무효·기권 1로 1표 차이 부결됐다.
- 조합은 10월 중 제6차 이사회에서 재상정하고 11월 중순 입찰공고를 목표로 했으나, 재상정 결과와 공고 여부는 이번 검색에서 확인하지 못했다.

## 점검할 리스크

- **단독 응찰 구조**: 목동4단지 등에서 경쟁이 없으면 유찰·수의계약 절차로 넘어갈 수 있다.
- **사업 변수**: 서계통합구역은 정비계획 변경 여부에 따라 공고 일정과 조건이 바뀐다.
- **속도 평가의 부작용**: 처리기한 중심 평가가 심의의 질보다 속도를 우선하게 만들 수 있다는 점은 지켜봐야 한다.
- **정보의 시차**: 일부 수치는 9~10월 보도 기준이므로 조합 공지와 정비사업 정보몽땅에서 최신 상태를 확인해야 한다.

## 체크포인트

- [ ] 11월 20일 자치구의 모범 조합 추천 마감, 12월 초 포상 결과 확인
