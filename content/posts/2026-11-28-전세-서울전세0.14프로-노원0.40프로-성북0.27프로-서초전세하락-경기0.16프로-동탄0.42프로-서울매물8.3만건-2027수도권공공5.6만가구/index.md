한국부동산원 11월 넷째 주(11월 23일 기준, 11월 26일 발표) 조사에서 서울 아파트 전세가격은 0.14% 올라 전주와 같은 상승률을 기록했습니다. 서울 매매가격이 0.01%로 94주 만에 가장 낮은 상승에 그친 것과 대비됩니다. 정부는 같은 날 2027년 수도권 공공주택 공급 계획을 내놓았습니다.

---

## 1. 11월 넷째 주 전세·매매 동향

한국부동산원 주간 동향(11월 23일 기준)입니다.

| 구분 | 전세 | 매매 |
|---|---|---|
| 서울 | 0.14% (전주와 동일) | 0.01% (94주 연속 상승, 94주 만에 최저) |
| 경기 | 0.16% (전주와 동일) | 0.17% (전주 0.21%) |
| 인천 | 0.08% | 0.02% |
| 수도권 | 0.14% | 0.10% |
| 전국 | 0.09% | 0.05% |
| 지방 | 0.03% | 0.00% |

- 전국 182개 시군구 중 매매는 101곳 상승, 9곳 보합, 72곳 하락이었습니다.
- 서울 전세 주간 상승률은 10월 둘째 주 0.18%, 셋째 주 0.16%, 넷째 주 0.17%, 11월 첫째·둘째 주 0.17%, 셋째 주 0.14%, 넷째 주 0.14%로 이어졌습니다.
- 올해 누적 전세 상승률은 11월 셋째 주 기준 서울 9.43%(전년 동기 2.77%), 경기 6.88%(전년 동기 1.29%)입니다. 이번 주 누적치는 확인하지 못했습니다.

## 2. 서울 자치구별 전세

| 구분 | 자치구 | 변동률 |
|---|---|---|
| 상승 | 노원 | 0.40% |
| 상승 | 금천 | 0.29% |
| 상승 | 성북 | 0.27% |
| 상승 | 도봉 | 0.20% |
| 상승 | 강서 | 0.17% |
| 상승 | 마포 | 0.16% |
| 상승 | 중랑 | 0.15% |
| 상승 | 강남 | 0.14% |
| 상승 | 양천 | 0.11% |
| 상승 | 송파 | 0.08% |
| 하락 | 서초 | -0.02% (반포·잠원동 구축 위주) |

- 뉴스핌 보도에 따르면 서울에서 서초구를 제외한 모든 자치구가 올랐습니다. 지난주 하락으로 돌아섰던 성동구는 이번 보도에서 별도 수치가 확인되지 않았습니다.
- 노원구가 0.40%로 1위에 올랐습니다. 지난 11월 26일 지역분석에서 다룬 노원의 매물 증가, 재건축 기대와 맞물려 있습니다. 다만 한 주 수치입니다.
- 강남 매매가 -0.34%로 16주 연속 내리는 가운데 강남 전세는 0.14% 올랐습니다. 매매와 전세의 방향이 다릅니다.

## 3. 경기·인천·지방 전세

| 지역 | 상승 상위 | 하락 |
|---|---|---|
| 경기 (0.16%) | 화성 동탄 0.42%, 광명 0.36%, 수원 영통 0.35%, 구리 0.35% | 이천 -0.19% |
| 인천 (0.08%) | 연수 0.19%, 부평 0.10%, 계양 0.09%, 영종 0.08% | 없음 |
| 지방 (0.03%) | 세종 0.26%, 부산 해운대 0.17%, 대구 중구 0.18% | 전남광주 -0.02%, 제주 -0.04% |

- 4대 광역시 전세는 0.04%(부산 0.05%, 대구 0.05%)입니다. 충남은 0.07%, 충북은 0.05%였습니다.
- 지방은 수도권과 달리 보합에 가까운 지역이 많습니다. 경북과 강원은 보합이었습니다.

## 4. 서울 매매와의 대비

| 항목 | 수치 |
|---|---|
| 서울 아파트 매매 | 0.01% (94주 만에 최저) |
| 강남 / 서초 / 송파 매매 | -0.34% / -0.30% / -0.50% |
| 강남·서초 연속 하락 | 16주 (8·3 세제개편 이후, 뉴스핌) |
| 송파 연속 하락 | 12주 |
| 한강벨트 | 강동 -0.03%, 성동·광진·영등포·동작 각 -0.01% |
| 하락 자치구 | 9곳 (시사저널e 제목 기준) |
| 서울 아파트 매물 (11월 25일) | 8만 3,000건 (연초 대비 +45.6%) |

- 매매는 강남권에서 한강벨트로 약세가 번지는데 전세는 오르는 구조입니다. 한 주 사이 하락 자치구가 늘었습니다.
- 머니투데이는 전세 매물 부족이 핵심 변수이며, 2027년 봄 이사철 수요가 늘면 전세와 매매 모두 상승 압력을 받을 수 있다는 전문가 분석을 전했습니다. 전망이지 확정이 아닙니다.
- 매매 매물은 늘고 전세 매물은 부족하다는 점이 지금 임대차 시장의 특징으로 보입니다.

## 5. 정부 2027년 수도권 공공주택 공급 계획

11월 26일 정부 브리핑 내용입니다(머니투데이 보도 재게시 기준).

| 항목 | 내용 |
|---|---|
| 2027년 수도권 공공주택 입주자 모집 | 5만 6,000가구 (공공분양 3만 5,000, 공공임대 2만 1,000) |
| 비교 | 최근 5년 연평균의 2배, 올해 전망 대비 44% 증가 |
| 공공임대 모집 시기 | 입주 1년 전에서 2년 6개월 전으로 앞당김 |
| 조기 모집 물량 | 수도권 9,000가구 |
| 미분양 매입확약 | LH 공공택지에서 모든 공공·민간택지로 확대 |
| 준공 후 미분양 | 수도권 비규제지역도 공공임대용으로 매입 |
| 신규 택지 발표에서 착공까지 | 68개월에서 37개월로 단축 |
| LH 입찰·계약 절차 | 약 절반으로 단축 |

- 김이탁 1차관은 토지거래허가구역 연장 여부는 시장 상황을 보고 판단하겠다고 밝혔습니다. 국토부는 전월세 시장을 모니터링하며 필요하면 조치하겠다는 입장도 냈습니다.
- 공공임대 모집을 앞당기는 것은 전세 수요 일부를 흡수하려는 조치로 읽힙니다. 다만 실제 입주는 대부분 2027년 이후라 당장의 전세 매물 부족을 해소하기는 어렵습니다.
- 서울 연립·다세대 원룸은 다방 자료상 전세 보증금과 월세가 전월 대비 하락해, 아파트와 소형 주택의 흐름이 갈립니다.

## 6. 시장 해석

- 서울 전세 0.14%는 2주 연속 같은 폭입니다. 둔화 흐름이 이어진 것은 아니며 정체로 보는 것이 정확합니다.
- 상승은 노원·성북·도봉·금천 등 강북·서남권 중저가 지역이 주도합니다. 매매가 약한 강남권도 전세는 오르고 있습니다.
- 매매 약세가 전세 안정으로 바로 이어지지 않았습니다. 지난 글에서 본 보증 한도 7억 원 초과 계약 확대, 월세 전환 흐름과 함께 보면 임차인 부담은 계속 커진 상태입니다.
- 공급 대책은 2027년 이후를 겨냥합니다. 올겨울과 내년 봄 이사철에는 매물 상황이 관건입니다.
- 이번 글의 수치는 보도 기사 기준이며, 이번 주 누적 상승률과 KB 11월 23일 기준 지수는 확인하지 못했습니다. R-ONE 원문과 대조가 필요할 수 있습니다.
