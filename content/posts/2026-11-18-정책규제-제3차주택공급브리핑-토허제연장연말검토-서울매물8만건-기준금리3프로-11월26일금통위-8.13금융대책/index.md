부동산 정책 시장은 **"정부는 하향 안정 신호를 강조하고, 규제는 연말 재검토 대기"** 국면이다. 이 글에서는 11월 13일 제3차 주택공급 정례브리핑, 토지거래허가제 연장 검토, 10월 금통위 의사록, 8·13 금융대책의 대출 규제 내용을 정리한다. 11월 금통위(26일) 결과와 규제지역 연장 여부는 아직 나오지 않았다.

---

## 1. 제3차 주택공급 정례브리핑(11월 13일)

국무조정실 브리핑 자료와 비즈니스워치(11월 13일) 보도 기준이다.

| 항목 | 수치·내용 |
|---|---|
| 서울 아파트 매매 상승률 | 7월 1.27% → 8월 1.05% → 9월 0.74% |
| 9월 하락 지역 | 강남 -1.65%, 서초 -1.25%, 송파 -0.45% |
| 연속 하락 | 강남·서초 14주, 강남3구 12주, 성동·강동 이번 주 하락 전환 |
| 서울 아파트 거래량 | 5월 8,900건 → 9월 3,900건(5년 평균 4,100건 밑돎) |
| 서울 아파트 매물(11일) | 8만 건 이상, 연초 대비 40% 이상 증가 |
| 최근 3주 전세·월세 매물 | 각각 5.0%, 10.6% 증가 |
| 서울 인허가(1~9월) | 전년 동기 대비 33% 증가, 아파트 3만 8,000가구(10년 평균 1.5배) |
| 서울 착공(1~9월) | 2만 2,000가구, 36% 증가 |

- 김영국 국토부 주택토지실장은 시장 전망을 예단하기 어렵다고 하면서도, 가격·거래·공급 선행지표·경매 매각가율·소비심리지수에서 하향 신호가 나타난다고 밝혔다.
- 불안 요인으로는 전월세 문제 지속과 서울 강북·경기 지역의 상승세를 꼽았다.
- 서울 아파트값은 92주 연속 상승 중이라 "하향 안정"과는 온도차가 있다. 상승률이 둔화한 것이지 하락 전환은 아니다.

## 2. 공급 계획과 입주 일정

| 구분 | 내용 |
|---|---|
| 수도권 입주 | 11~12월 약 1만 6,000가구, 2027년 1분기 약 2만 8,000가구(합계 4만 4,000가구 안팎) |
| 월별 입주(수도권 아파트) | 11월 6,282 / 12월 10,225 / 1월 5,323 / 2월 9,594 / 3월 12,744가구 |
| 분양 | 10월 약 1만 6,000가구(고덕강일 1,305가구 포함), 연말까지 약 1만 1,000가구 추가 |
| LH 민간참여 공공주택 | 10개 블록 약 9,000가구, 6개 블록(5,782가구)은 13일 공고, 나머지 약 3,000가구는 12월까지 |
| 지분적립형 | 고양창릉 284가구(12월), 분양가 25% 납부 후 나머지 20년 분납 |
| 신규택지 | 수도권 7만 7,000가구 규모 |
| 제도개선 | 8·13 대책 후속 145건 중 65건 완료, 80건 추진 중 |

- 3기 신도시 선행지구 이주율은 7월 53%에서 10월 91%로 올랐다.
- 12월에 인허가·금융 애로 통합지원센터가 운영되고, 12월 말 주요 사업 디지털 대시보드가 공개될 예정이다.

## 3. 토지거래허가제와 규제지역: 연말 검토

| 항목 | 내용 |
|---|---|
| 현재 토지거래허가구역 | 서울 전역, 경기 12개 지역(연말까지 적용) |
| 검토 방식 | 연말까지 시장 모니터링 후 조정대상지역·투기과열지구와 함께 종합 검토 |
| 확정 여부 | 연장·해제 모두 미확정 |

- 지난 11월 11일 글에서 다룬 추가 대책설(부천·수원 권선·안양 만안 규제지역 추가)은 국토부가 허위로 규정했고, 이번 브리핑에도 해당 내용은 없었다.
- 연말 판단은 서울 가격 둔화가 이어지는지, 강북·경기 상승세가 잡히는지에 달려 있다.

## 4. 알박기 대책과 공공재개발

- 정부는 이재명 대통령 지시에 따른 부동산 '알박기' 대책으로 이행강제금 시행을 앞두고 있고, 내년 3월 협조 장려금도 시행한다. 관련 법률안도 검토 중이다.
- 9월 입법예고 기준 토지보상법 시행령 개정안은 이행기간 최대 3개월, 이행강제금 상한 1,000만 원, 최초 부과 시 50% 범위 감경이다. 입법예고 내용이라 확정 여부는 별도 확인이 필요하다.
- 광명시흥 보상은 착수 기간이 4개월 단축되고 보상비가 1조 3,000억 원 늘어 총 6조 8,000억 원이 됐다.
- 국토부 보도자료 목록에 공공재개발 사업수수료 한시 인하(3%에서 1%) 건이 11월 12일자로 올라와 있으나, 제목만 확인했고 본문은 확인하지 못했다.

## 5. 한국은행: 10월 의사록과 11월 26일 금통위

연합뉴스·한국시민센터 보도(11월 10일) 기준이다.

| 항목 | 내용 |
|---|---|
| 기준금리 | 연 3.00%(10월 22일 동결, 7명 만장일치) |
| 의사록 기조 | 7·8월 두 차례 인상 효과를 점검할 필요, 긴축 기조 지속 필요 의견 |
| 가계부채 | 취약차주 연체율이 매우 높은 수준이라 대비 필요 |
| 자산시장 | 주가 상승 시 차익실현 자금 일부가 부동산으로 이동 가능, 주가 조정 시 소비·주택 구매 여력 감소 |
| 환율 | 원/달러 하락 속도 2023년 초 이후 가장 빠름 |
| 다음 회의 | 11월 26일 |

- 시장에서는 11월 3.25% 인상 전망과 취약차주 부담을 고려한 동결 전망이 엇갈린다. 결과는 확정되지 않았다.
- 의사록에 부동산 가격을 직접 겨냥한 발언은 없고, 주식시장 자금 이동 가능성이 언급된 정도다.

## 6. 대출 규제: 8·13 금융대책 요약

머니투데이방송(8월 13일) 보도 기준이며, 현재 시행 중인 틀이다.

| 항목 | 내용 |
|---|---|
| 2026년 가계대출 증가율 목표 | 1.5% → 약 3% 상향 |
| 주택공급 금융지원 | 26조 3,000억 원 → 약 47조 8,000억 원 |
| 갭투자 전세대출 | 수도권·규제지역 비거주 1주택자 전세대출 신규·연장 원칙적 제한, 보증비율 80% → 70% |
| DSR 소득 산정 | 전년 소득 20% 초과 증가 시 2년 평균, 30% 초과 시 3년 평균 |
| 은행 규제 | 일부 주담대 위험가중치 상향(세부안 4분기), 가계 시스템리스크 완충자본 도입 |
| 청년 상품 | 만 39세 이하 생애최초, 소득 7,000만 원 이하, LTV 80%, 비아파트 4억 원 이하 |

- 총량 목표 상향은 정비사업 이주비·분양 중도금 대출이 막히던 문제를 풀기 위한 것으로, 수요 억제 규제가 풀린 것은 아니다.
- 금융위는 11월 초 "엄격한 관리 기조 당분간 불가피" 입장을 유지했다.

## 7. 실수요자·투자자 관점 정리

- **매수 대기자:** 매물이 늘고 거래가 줄어 협상 여지는 커졌다. 다만 서울 전체는 여전히 상승 중이므로 지역별 편차를 확인해야 한다.
- **토허제 지역 거주·투자자:** 연말 연장 여부에 따라 실거주 요건이 달라진다. 확정 전 소문보다 국토부·서울시 공고를 기준으로 삼는다.
- **변동금리 대출자:** 기준금리 3.00%에서 11월 26일 인상 가능성이 열려 있어, 이자 부담 증가 시나리오를 점검해야 한다.
- **전세 수요자:** 전월세 매물은 늘었으나 정부도 전월세 문제 지속을 불안 요인으로 꼽았다. 갭투자 전세대출 제한 대상인지 확인이 필요하다.
