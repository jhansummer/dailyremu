서울 대형 재건축 단지의 시공사 선정이 11월 이후 본격화되지만, 잠실장미처럼 조합 내부 의결 단계에서 일정이 밀리는 사례도 나온다. **이 글에서는 잠실장미의 일정 지연 배경, 목동7단지와 성산시영의 사업 규모와 수주전 구도, 11월에 마감되는 입찰 일정, 점검할 리스크를 정리한다.**

---

## 1. 잠실장미: 입찰 방식안 1표 차 부결

머니투데이방송(10월 8일) 보도 기준이다.

| 항목 | 내용 |
|---|---|
| 사업 규모 | 기존 3,522가구 → 최고 49층 5,101가구 |
| 공사비 | 시장 추정 3조원대(조합 공식 수치 아님) |
| 9월 18일 이사회 | 정족수 미달로 안건 상정 없이 산회 |
| 9월 30일 이사회 | 입찰 방식·선정 계획안 부결(참석 12명 중 찬성 5, 반대 6, 무효·기권 1) |
| 부결 사유 | 입찰 조건 등을 둘러싼 이견. 입찰공고문·입찰안내서·계약서(안) 수정 중 |
| 기존 계획 | 9월 입찰공고, 내년 1월 시공사 선정 |
| 변경 계획 | 11월 중순 입찰공고, 내년 상반기 선정. 10월 중 6차 이사회에서 안건 재상정 |
| 수주 구도 | 현대건설이 잠실에 홍보관(디에이치 라운지)을 열고 가장 적극적, 롯데건설은 입찰 조건과 사업 현황 검토 중 |

부결 이후 재상정 안건이 통과되는지가 11월 입찰공고 시점을 좌우한다. 재상정 결과는 이번 조사에서 확인하지 못했다.

## 2. 목동7단지: 조합설립 후 수주전 본격화

머니투데이방송(6월 7일) 보도 기준이며, 이후 진행 상황은 확인이 필요하다.

| 항목 | 내용 |
|---|---|
| 창립총회 | 안건 10개 모두 통과, 토지등소유자 95% 이상 찬성 |
| 동의율 | 2,620명 중 2,342명(89.4%) 동의 |
| 사업 규모 | 기존 최고 15층 2,550가구 → 최고 49층 4,341가구 |
| 현황 | 용적률 약 125%, 평균 대지지분 64㎡(약 19.3평) |
| 일정(당시 계획) | 6월 24일 조합설립인가 신청, 8월 통합심의 접수, 10~11월 중 시공사 입찰공고 |
| 수주 구도 | 삼성물산·현대건설 유력, 롯데건설은 홍보관 준비. 총회장에 GS건설·DL이앤씨 관계자도 참석 |

## 3. 성산시영: 컨소시엄 금지, 경쟁입찰 기대

머니투데이방송(6월 16일) 보도 기준이다.

| 항목 | 내용 |
|---|---|
| 정비계획 변경 | 최고 40층 → 46층, 4,823가구 → 4,833가구(일반분양 10가구 증가), 5월 14일 마포구 접수 |
| 동의율 | 토지등소유자 3,771명 중 97.48% 찬성, 특별건축구역 요건(3분의 2) 충족 |
| 입찰 방식 | 조합이 컨소시엄 불허 방침을 건설사에 구두 통지 |
| 관심 건설사 | 삼성물산, 현대건설, 대우건설, GS건설, HDC현대산업개발 |
| 목표 일정 | 통합심의 후 2027년 상반기 시공사 선정 총회, 2027년 하반기 사업시행계획인가 |

## 4. 11월 예정된 입찰·총회 일정

지난 10월 25일 글에서 정리한 하우징헤럴드 기준 일정이며, 변동될 수 있다.

| 일자 | 사업지 | 내용 |
|---|---|---|
| 11월 16일 | 목동4단지 | 입찰 마감(3.3㎡당 1,010만원, 총 약 1조 6,389억원) |
| 11월 16일 | 여의도 시범 | 삼성물산 시공사 총회 |
| 11월 18일 | 목동10단지 | 현대건설 시공사 총회 |
| 11월 24일 | 반포푸르지오·이수 신동아4단지 | 리모델링 시공사 총회(삼성물산·포스코이앤씨) |
| 11월 25일 | 오금현대 | 입찰 마감(3.3㎡당 962만원, 총 약 1조 6,642억원) |
| 11월 30일 | 여의도 진주 | 입찰 마감(3.3㎡당 1,260만원) |
| 11월 중순(예정) | 잠실장미 | 입찰공고 목표 |

## 5. 점검할 리스크

- **조합 내부 의결 지연**: 잠실장미처럼 이사회 부결 한 번으로 선정 시점이 반년 가까이 밀릴 수 있다.
- **공사비 논란**: 입찰 조건과 공사비를 둘러싼 이견은 계약 단계에서 증액 갈등으로 이어질 수 있다.
- **단독 응찰**: 경쟁이 약하면 수의계약으로 넘어가 공사비 협상력이 떨어질 수 있다.
- **일정 불확실성**: 목동7단지의 인가·입찰공고, 성산시영의 통합심의는 최신 진행 상황을 이번 조사에서 확인하지 못했다. 조합 공지와 서울시 정비사업 정보몽땅에서 확인이 필요하다.
